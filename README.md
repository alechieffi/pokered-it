# Pokémon Versione Rossa e Blu
This is a disassembly of Pokémon Versione Rossa and Pokémon Versione Blu.  It builds the following ROMs:

Pokémon Versione Rossa.gbc #sha1: 4B34CBF103588F01799E4E35BD76DEF94A9E3008

Pokémon Versione Blu.gbc   #sha1: A73E451FB626526A2A8DD25CF5CCC4903B4D7C3B

pokeblue_debug.gbc         #sha1: 40CA93E0A787BFCA7D6AB3157889F28773452551

To set up the repository, see https://github.com/alechieffi/pokered-it/blob/main/INSTALL.md
